# Reserva de asiento en sala de cine

## Nombre del estudiante

Jonathan Oswaldo Chicaiza Andrango

## Objetivo

Crear un programa en Python que permita reservar un asiento de una sala de cine de 3 filas por 4 columnas.

## Funcionamiento

El programa solicita al usuario la fila y la columna del asiento que desea reservar. Después, el asiento seleccionado cambia de 0 a 1 y se muestra el estado completo de la sala.

- 0 = asiento libre
- 1 = asiento reservado

## Cómo ejecutar el programa

Abrir el archivo `reserva_cine.py` en Visual Studio Code y ejecutar el programa. Luego ingresar la fila y la columna del asiento que se desea reservar.
